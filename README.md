Calculadora de Propinas y Consumo
Una calculadora de propinas y consumo construida con Vite, React, TypeScript y Tailwind CSS. Este proyecto permite a los usuarios calcular rápidamente las propinas y el total de su consumo.

Características:

Campos de entrada dinámicos para el monto de la cuenta y el porcentaje de propina.
Cálculos en tiempo real del monto total, propina por persona y más.
Diseño responsivo, construido con Tailwind CSS para una experiencia de usuario fluida.
Migración de la gestión del estado a useReducer para un mejor manejo de la lógica de estado compleja.
